# NEXO-COMERCIAL

Projeto independente de oficina didática para apoiar uma agência FICTÍCIA na preparação de propostas com catálogo controlado.

## Referências de controle
- Estado operacional, pendências e situação dos papéis: state/STATE.md.
- Autoridade e pasta autorizada: contracts/AUTHORITY.md.
- Decisões confirmadas: memory/DECISIONS.md.
- Histórico de execução e validação: logs/WORKLOG.md.

## Uso
Ler AGENTS.md na ordem indicada. As fontes canônicas estão em data/. As entregas internas estão em outputs/. Consultar state/STATE.md antes de agir; novas atividades dependem de instrução humana.

## Fluxo
Validação das fontes → delegação explícita → análise → redação → revisão → validação humana da entrega.

A revisão documental não constitui aprovação humana ou autorização de envio.
